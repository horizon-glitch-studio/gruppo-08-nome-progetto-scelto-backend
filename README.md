# Will of the Void – Backend

Backend del gioco di carte collezionabili digitale **Will of the Void**, progetto del Laboratorio Integrato (gruppo 08).

Stack: Java 21, Spring Boot 3, PostgreSQL. Il codice verrà aggiunto nelle prossime fasi.
